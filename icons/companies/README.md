# Company logos

Logos of the AI companies shown in the model picker, from
[LobeHub Icons](https://github.com/lobehub/lobe-icons) (`@lobehub/icons-static-svg` 1.95.1,
MIT license, Copyright (c) LobeHub). The logos are trademarks of their owners and are
used only to identify each company's models.

`COMPANY_LOGOS` in `index.html` maps each OpenRouter author slug (the part of the model
ID before the `/`) to a file here; companies without a logo keep their initial.
